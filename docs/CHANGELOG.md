# Changelog

История доработок пайплайна базы знаний / индекса, вне учебных заданий Task-1…5.

---

## 2026-07-20 — Мультиязычность пайплайна + личная база «Паттерны проектирования» (RU)

### Задача

Нужна была русскоязычная база знаний для чат-бота по теме solution/software
architecture. Источник — refactoring.guru/ru (каталог паттернов проектирования GoF).

### Ограничение по копирайту

У refactoring.guru — «Все права защищены» + Content Usage Policy, разрешающая только
цитирование несущественной части статьи с атрибуцией (не массовое копирование полного
текста). Совместно с пользователем принято решение: скачать полный текст **только для
личного использования**, не публиковать и не пушить в этот репозиторий — репозиторий
публичный (`github.com/akrasnikov-practicum-yandex/quantum-forge-software`) и привязан к
учебному submission.

Практическое следствие: новая база и её индекс добавлены в `.gitignore` и физически не
попадают в git-историю проекта.

### Добавлено

- **`knowledge_base_arch/`** *(локально, не в git)* — 22 документа по паттернам
  проектирования GoF на русском (creational/structural/behavioral), каждый с
  YAML-frontmatter (`title`, `category`, `lang: ru`, `source_url`) для атрибуции
  источника.
- **`index_arch/`** *(локально, не в git)* — FAISS-индекс над `knowledge_base_arch/`,
  собран embedding-моделью `paraphrase-multilingual-MiniLM-L12-v2`.
- **`docs/LOAD_DATABASE.md`** — руководство «как загрузить новую базу знаний» (полный
  конвейер: исходники → `knowledge_base/` → индекс → бот; флаги; Docker; частые проблемы).
- Флаг **`--kb-dir`** в `scripts/build_index.py` — каталог с документами базы можно
  указать явно, вместо жёстко заданного `knowledge_base/`. Позволяет держать несколько
  независимых баз (учебную и личную) без взаимного влияния.
- Флаг **`--model`** в `scripts/build_index.py`, `scripts/query_index.py`,
  `scripts/rag_bot.py` — embedding-модель можно переопределить из CLI. Нужно для
  не-английских корпусов: модель по умолчанию (`all-MiniLM-L6-v2`) обучена в основном на
  английском и даёт слабый семантический поиск на русском.

### Проверено

- До смены модели: запрос «Как избежать создания нескольких экземпляров одного класса?»
  на индексе с `all-MiniLM-L6-v2` **не находил** паттерн «Одиночка» в топ-4.
- После пересборки с `paraphrase-multilingual-MiniLM-L12-v2` (та же размерность,
  dim=384 — drop-in замена): тот же запрос → «Одиночка» на 2–3 месте; отдельный запрос
  про уведомление объектов об изменении состояния → «Наблюдатель» корректно найден.

### Изменено

- `.gitignore` — исключены `knowledge_base_arch/`, `index_arch/`.
- `README.md` — добавлена ссылка на `docs/LOAD_DATABASE.md`.

### Не затронуто

- Учебный корпус `knowledge_base/` → `index/` (Astral Strife, Задания 1–5) и поведение
  скриптов по умолчанию (без новых флагов) — без изменений.
